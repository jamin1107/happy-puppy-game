# 快乐小狗寻回记

一款 H5 解谜冒险游戏。

## 故事背景

天成花园小区陈记茶叶店的快乐小狗"金宝"走丢了。玩家需要穿越小区各个角落，在白天与黑夜之间寻找线索，最终找回金宝。

## 游戏特色

- **多场景探索**：小区、茶叶店、快递驿站、幼儿园、地下车库（B1/B2）、SM商场、好邻居超市、荻花洲海边
- **昼夜系统**：部分NPC和线索只在夜晚出现（22:00后）
- **时间跳过**：可快速跳过1-5小时，避免长时间等待
- **物品系统**：购买烟、狗粮、猫粮等道具触发不同剧情
- **解谜元素**：推箱子谜题、线索追踪
- **多结局**：根据玩家的选择和探索程度，体验不同结局

## 游戏流程

1. 在茶叶店接受老陈的委托
2. 在小区寻找金宝的爪印线索
3. 询问王阿姨获取目击信息
4. 前往好邻居超市买烟
5. 给幼儿园门卫大爷送烟解锁地下车库
6. 在车库B1/B2层追踪金宝踪迹
7. （支线）开车去荻花洲海边寻找额外线索
8. 夜晚在快递驿站找黑白小猫"墨墨"获取关键信息
9. 前往SM商场东侧仓库解开谜题救出金宝
10. 将金宝送回茶叶店

## 操作方式

- **键盘**：WASD / 方向键移动，空格键交互
- **手机**：左下角摇杆移动，右下角按钮交互
- **时间跳过**：右上角 +1h ~ +5h 按钮

## 技术栈

- 纯 HTML5 + Canvas + JavaScript
- 无外部依赖，单文件部署
- 响应式设计，支持桌面和移动端
